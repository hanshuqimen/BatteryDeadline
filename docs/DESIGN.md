# Interface direction

A quiet Windows utility centered on a chosen time. A horizontal battery-to-deadline journey is the signature element; supporting readings sit underneath as simple aligned rows. Avoid a dense sensor grid.

Tokens: canvas #f5f7fa, surface #ffffff, text #172333, secondary #566477, accent #226847, warning #8a5105, divider #dce2e9. Use Segoe UI Variable / Segoe UI and system fallbacks, tabular numerals, 14–16 px body text and 48 px deadline text. Dark tokens use #151c25, #1e2834, #f3f6fa, #b1bdcb and #80d7a3.

Layout: 190 px sidebar, flexible content with max width 1040 px, a deadline editor and clear session action, then current status, reserve-time prediction, a truthful rolling power chart, and an expandable activity list. Collapse navigation to a top row on small windows. Icons are one consistent SVG stroke family. All controls have labels, keyboard focus and a minimum 40 px desktop hit area. Settings are disabled during a session to avoid changing its contract midway.

The skills' generic neumorphic marketing recommendation was discarded: low-contrast embossing and testimonials do not help a local battery utility. The product's calm, minimal, Windows-friendly brief determines the final design. No remote fonts, animations in the background, fictitious sensor data, or placeholder controls.
