# Changelog

## 0.1.0 — 2026-10-05

Initial Windows 11 x64 preview: real battery telemetry, reserve-aware estimates, conservative deadline control, brightness/refresh/DC CPU adapters, verified persistent recovery, manual override protection, tray, four desktop pages, SQLite history, local diagnostics, CLI, simulation, automated safety tests, and NSIS/portable distribution.

Offline Simplified Chinese/English/Japanese UI and native tray, Windows language detection, persistent runtime language switching, locale-aware dates/numbers, and English/Chinese READMEs.

EcoQoS is deferred. Hardware mutation while discharging, Modern Standby, multi-battery behavior on physical devices, and long-term overhead remain subject to cross-device validation. No guaranteed runtime or causal energy-savings claim is made.
